AI융합 간호정보학 학습 도우미

본 챗봇은 간호학과 전공교과목 「AI융합 간호정보학」 전용 학습 지원 인공지능입니다. 이용을 위해 Anthropic API 키를 입력하고 사용자 유형을 선택해 주십시오.

보안 고지
입력하신 API 키는 서버로 전송되지 않으며 브라우저 localStorage에만 저장됩니다. 공용 PC에서는 사용 후 반드시 '키 삭제'를 실행하십시오. 사용량과 과금은 본인 계정에 청구됩니다.

키가 없으시면 console.anthropic.com에서 발급받으실 수 있습니다. 붙여넣기(⌘V / Ctrl+V)를 지원합니다.

향후 모델 갱신에 대응하기 위해 모델 ID를 직접 수정할 수 있습니다. 실제 요청에는 위 입력 필드의 값이 사용됩니다.

사용자 유형

교수자 모드는 담당 교수만 사용할 수 있습니다. 잠금 해제 상태는 이 탭을 닫으면 사라집니다.
