# AI-NI_ChatBot

간호학과 전공교과목 **「AI융합 간호정보학(Nursing Informatics with AI)」** 전용 학습 지원 챗봇입니다.

**바로가기 → https://jp5678.github.io/AI-NI_ChatBot/**

---

## 특징

- **교과목 전용 범위 통제** — 간호정보학 관련 18개 영역에 한정하여 답변합니다.
- **2단계 범위 판정** — 경량 모델이 질문 범위를 먼저 판정하고, 범위 밖이면 본 모델을 호출하지 않습니다. 비용이 절감되고 우회 시도 차단률이 높아집니다.
- **검증된 출처만 인용** — 제도·통계·연구 결과는 웹 검색으로 확인한 뒤 답변하며, 검색으로 확인되지 않은 답변에는 `내부지식 기반 · 출처 미검증` 배지가 자동으로 붙습니다.
- **학습자 / 교수자 모드** — 설명 깊이, 문항 제작 방식(Bloom 수준 명시), 수업 설계 지원이 달라집니다.
- **단일 HTML 파일** — 설치·빌드·서버가 필요 없습니다. 외부 리소스는 Google Fonts뿐입니다.
- **접근성** — 다크/라이트 모드 모두 WCAG AA(명도대비 4.5:1) 기준을 충족합니다. 모바일 480px까지 대응합니다.

## 사용 방법

1. https://jp5678.github.io/AI-NI_ChatBot/ 에 접속합니다.
2. [console.anthropic.com](https://console.anthropic.com) 에서 발급받은 본인의 API 키를 입력합니다.
3. 모델과 사용자 유형(학습자 / 교수자)을 선택하고 대화를 시작합니다.

> **API 키 안내** — 입력한 키는 서버로 전송되지 않으며 브라우저 localStorage에만 저장됩니다. 공용 PC에서는 사용 후 반드시 '키 삭제'를 실행하십시오. 사용량과 과금은 본인 계정에 청구됩니다.

자세한 내용은 [시스템 안내 및 사용 매뉴얼](AI-NI_ChatBot_사용매뉴얼.docx)을 참고하십시오.

## 로컬 실행

`file://` 로 직접 열면 브라우저 보안 정책(CORS)에 따라 API 호출이 차단될 수 있습니다. 간이 웹서버로 실행하십시오.

```bash
python3 -m http.server 8787
```

이후 http://localhost:8787/ni-bot.html 로 접속합니다.

## 품질 검증

`test-c2.html` 은 12개 필수 케이스를 자동 채점합니다. 챗봇과 동일한 시스템 지침을 그대로 불러와 실행하므로, 지침을 수정하면 테스트도 함께 갱신됩니다. 논문 추천 케이스에서는 답변에 등장하는 모든 URL·DOI를 실제 검색 결과와 대조하여 **근거 없는 출처가 하나라도 있으면 실패로 처리**합니다.

> 하네스는 실제 API를 최대 24회 호출하므로 과금이 발생합니다.

배포 전 점검 결과(2026-07-29 실측): API 키 미입력 시 렌더링 · 새로고침 복원 · 중단/오류 시 이력 보존 · 출처 URL 무결성 · 모바일 480px · 명도대비 24개 조합 — 전 항목 통과.

## 알려진 제약

1. **최신 정보는 웹 검색 없이 불가능합니다.** 검색을 끄면 학습 데이터 컷오프 시점의 정보만 제공됩니다.
2. **출처 강제는 환각을 유발할 수 있습니다.** 본 시스템은 "확인되지 않은 출처는 제시하지 말고 미검증임을 표시하라"는 규정으로 이를 억제하며, 정기 재검증을 권장합니다.
3. **클라이언트 측 API 키는 구조적으로 안전하지 않습니다.** 학생 배포 시에는 각자 키를 발급받아 사용해야 하며, 교수자 키를 공유해서는 안 됩니다. 키를 서버에 두려면 별도의 프록시가 필요합니다.
4. **프롬프트 기반 가드레일에는 한계가 있습니다.** 사전 범위 판정 단계가 이를 보완하므로 끄지 마십시오.

## 배포

`index` 브랜치에 푸시하면 GitHub Actions가 `ni-bot.html` 을 `index.html` 로 복사하여 GitHub Pages에 자동 배포합니다.
